---

## 🎯 Obiettivo
Individuare il punto di origine di un rumore all’interno di una parete, usando i tempi di arrivo del suono rilevati da più microfoni.

---

## 🧩 Modello di propagazione del suono nel muro

### 1. **Assunzioni di base**
- Il muro è un mezzo omogeneo (es. cemento, laterizio).
- Il suono si propaga in modo isotropo (uguale in tutte le direzioni).
- La velocità del suono nel materiale è nota o stimabile (es. ~3000 m/s nel cemento).
- I microfoni sono appoggiati su diverse pareti o punti della stessa parete.

---

### 2. **Metodo: Triangolazione acustica**

#### 📍 Fasi operative:

1. **Registrazione dei tempi di arrivo**  
   Ogni microfono registra il tempo in cui riceve il segnale acustico.

2. **Calcolo delle differenze di tempo (TDOA)**  
   Si calcolano le differenze di tempo tra le coppie di microfoni:
   \[
   \Delta t_{ij} = t_i - t_j
   \]

3. **Equazioni di distanza**  
   Sapendo la velocità del suono \( v \), si ottiene la differenza di distanza:
   \[
   d_i - d_j = v \cdot \Delta t_{ij}
   \]

4. **Sistema di equazioni**  
   Con almeno 3 microfoni (meglio 4 o più), si può risolvere un sistema di equazioni per trovare le coordinate della sorgente sonora.

---

## 🧮 Esempio semplificato (2D)

Immagina 3 microfoni posizionati così:

| Microfono | Posizione (x, y) |
|-----------|------------------|
| M1        | (0, 0)           |
| M2        | (1, 0)           |
| M3        | (0, 1)           |

Se il suono arriva a M1 a \( t_1 \), a M2 a \( t_2 \), e a M3 a \( t_3 \), puoi calcolare le differenze di tempo e risolvere per trovare il punto \( (x, y) \) da cui è partito il suono.

🧾 Codice C# semplificato
csharp
using System;
using System.Collections.Generic;
using MathNet.Numerics.LinearAlgebra;

public class SoundLocalization
{
    public struct Microphone
    {
        public double X;
        public double Y;
        public double TimeDelay; // rispetto al microfono di riferimento

        public Microphone(double x, double y, double delay)
        {
            X = x;
            Y = y;
            TimeDelay = delay;
        }
    }

    public static (double x, double y) LocalizeSource(List<Microphone> mics, double soundSpeed)
    {
        int n = mics.Count;
        if (n < 4) throw new ArgumentException("Servono almeno 4 microfoni per una buona stima.");

        var A = Matrix<double>.Build.Dense(n - 1, 2);
        var b = Vector<double>.Build.Dense(n - 1);

        var refMic = mics[0];

        for (int i = 1; i < n; i++)
        {
            var mic = mics[i];
            double dx = mic.X - refMic.X;
            double dy = mic.Y - refMic.Y;
            double dt = mic.TimeDelay;

            A[i - 1, 0] = dx;
            A[i - 1, 1] = dy;

            b[i - 1] = 0.5 * (dx * dx + dy * dy - Math.Pow(soundSpeed * dt, 2));
        }

        var At = A.Transpose();
        var AtA = At * A;
        var Atb = At * b;

        var solution = AtA.Solve(Atb);

        return (refMic.X + solution[0], refMic.Y + solution[1]);
    }

    // Esempio d'uso
    public static void Main()
    {
        double v = 3000; // velocità del suono nel muro (m/s)

        var microfoni = new List<Microphone>
        {
            new Microphone(0, 0, 0),
            new Microphone(1, 0, 0.0001),
            new Microphone(0, 1, 0.00015),
            new Microphone(1, 1, 0.0002)
        };

        var (x, y) = LocalizeSource(microfoni, v);
        Console.WriteLine($"Sorgente stimata in: ({x:F4}, {y:F4}) metri");
    }
}

## 🎯 Obiettivo aggiornato
Stimare la posizione della sorgente sonora in presenza di **rumore nei dati** (es. errori nei tempi di arrivo) usando un approccio più robusto.

## 🧪 Estensioni del modello

### 1. **Errori di misura**
I tempi di arrivo possono essere affetti da:
- Rumore elettronico nei microfoni
- Riflessi e riverberi nel muro
- Errori di sincronizzazione

Per modellare questo, possiamo assumere che ogni tempo di arrivo \( t_i \) sia:
\[
t_i = t_{\text{vero}} + \varepsilon_i
\]
dove \( \varepsilon_i \sim \mathcal{N}(0, \sigma^2) \) è un errore gaussiano.

---

### 2. **Filtro di stima: Minimi quadrati pesati (WLS)**

Invece di risolvere il sistema lineare semplice, possiamo usare una versione **pesata** che minimizza l’errore quadratico tenendo conto della varianza di ciascuna misura.

### 3. **Filtro iterativo: Gauss-Newton**

Per maggiore precisione, possiamo usare un algoritmo **non lineare iterativo** come il **Gauss-Newton** per stimare la posizione della sorgente. Questo è utile quando i microfoni non sono disposti in modo simmetrico o i ritardi sono molto piccoli.

## 🧠 Concetto base

Quando un suono si propaga da un punto all’interno del muro, arriva ai microfoni con **tempi diversi**. Se conosciamo:

- la posizione dei microfoni
- la velocità del suono nel materiale
- i tempi di arrivo (anche se affetti da errori)

…possiamo stimare la posizione della sorgente.

---

## ⚠️ Il problema degli errori

Nella realtà, i tempi di arrivo non sono perfetti. Possono essere disturbati da:
- **rumore elettronico**
- **riflessioni** del suono
- **imprecisioni di sincronizzazione**

Quindi, se usassimo un metodo diretto (come quello lineare), otterremmo una posizione **distorta**.

---

## 🧮 Soluzione: Metodo di Gauss-Newton

Il metodo di **Gauss-Newton** è un algoritmo iterativo per risolvere problemi **non lineari** di ottimizzazione. Funziona così:

### 1. **Definizione del modello**
Per ogni microfono \( i \), la distanza dalla sorgente \( (x, y) \) è:
\[
d_i = \sqrt{(x - x_i)^2 + (y - y_i)^2}
\]
Il tempo previsto di arrivo è:
\[
t_i^{\text{previsto}} = \frac{d_i}{v}
\]
dove \( v \) è la velocità del suono.

### 2. **Errore di misura**
Confrontiamo il tempo previsto con quello misurato:
\[
e_i = t_i^{\text{misurato}} - t_i^{\text{previsto}}
\]

### 3. **Minimizzazione dell’errore totale**
L’obiettivo è trovare \( (x, y) \) che **minimizza la somma dei quadrati degli errori**:
\[
\min_{x, y} \sum_i e_i^2
\]

### 4. **Iterazione**
Partendo da una stima iniziale (es. il centro dei microfoni), il metodo aggiorna la posizione stimata passo dopo passo, migliorando la precisione ad ogni iterazione.

---

## ✅ Vantaggi

- Tiene conto degli **errori di misura**
- Funziona anche con **microfoni disposti in modo irregolare**
- Può essere esteso facilmente al **3D**

## 🧾 Codice C# – Localizzazione con Gauss-Newton

```csharp
using System;
using System.Collections.Generic;
using MathNet.Numerics.LinearAlgebra;

public class GaussNewtonLocalization
{
    public struct Microphone
    {
        public double X;
        public double Y;
        public double Time;

        public Microphone(double x, double y, double time)
        {
            X = x;
            Y = y;
            Time = time;
        }
    }

    public static (double x, double y) EstimateSource(List<Microphone> mics, double soundSpeed, int maxIterations = 100, double tolerance = 1e-6)
    {
        if (mics.Count < 4)
            throw new ArgumentException("Servono almeno 4 microfoni per una stima robusta.");

        // Stima iniziale: centroide dei microfoni
        double x = 0, y = 0;
        foreach (var mic in mics)
        {
            x += mic.X;
            y += mic.Y;
        }
        x /= mics.Count;
        y /= mics.Count;

        for (int iter = 0; iter < maxIterations; iter++)
        {
            var J = Matrix<double>.Build.Dense(mics.Count, 2); // Jacobiano
            var r = Vector<double>.Build.Dense(mics.Count);    // Residui

            for (int i = 0; i < mics.Count; i++)
            {
                var mic = mics[i];
                double dx = x - mic.X;
                double dy = y - mic.Y;
                double dist = Math.Sqrt(dx * dx + dy * dy);
                double predictedTime = dist / soundSpeed;
                double residual = mic.Time - predictedTime;

                r[i] = residual;

                if (dist > 1e-6)
                {
                    J[i, 0] = -dx / (soundSpeed * dist);
                    J[i, 1] = -dy / (soundSpeed * dist);
                }
            }

            var JT = J.Transpose();
            var H = JT * J; // Hessiana approssimata
            var g = JT * r; // Gradiente

            var delta = H.Solve(g);

            x += delta[0];
            y += delta[1];

            if (delta.L2Norm() < tolerance)
                break;
        }

        return (x, y);
    }

    public static void Main()
    {
        double v = 3000; // velocità del suono nel muro (m/s)

        var microfoni = new List<Microphone>
        {
            new Microphone(0, 0, 0.00000),
            new Microphone(1, 0, 0.00032),
            new Microphone(0, 1, 0.00028),
            new Microphone(1, 1, 0.00045)
        };

        var (x, y) = EstimateSource(microfoni, v);
        Console.WriteLine($"Sorgente stimata in: ({x:F4}, {y:F4}) metri");
    }
}
```
